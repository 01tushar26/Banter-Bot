# Banter-Bot 🤖

Banter-Bot is a simple AI-powered chatbot built using **React.js**, **Appwrite** for authentication, and **Google Gemini AI** for generating responses.

## 🔧 Tech Stack

- React.js (Frontend)
- Appwrite (Authentication)
- Google Generative AI (Gemini API)
- Context API (State Management)
- Vite (Development Server)

## 🚀 Features

- Secure user login/signup
- Real-time AI chat interface
- Typing animation for responses
- Prompt suggestions
- Simple, clean UI
